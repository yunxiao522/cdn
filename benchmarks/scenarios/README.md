# Benchmark Scenario Plans

Store versioned, reproducible workload definitions here after selecting a
runtime and benchmark tool. Each scenario should specify input rate and event
sizes, partition distribution, source and sink behavior, duration, warm-up,
resource limits, and pass/fail thresholds.

No benchmark executable, workload definition, or measured result is currently
included. See [../../docs/performance-capacity.md](../../docs/performance-capacity.md)
for the planning methodology and required scenario coverage.
